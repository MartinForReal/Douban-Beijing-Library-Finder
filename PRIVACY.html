隐私政策 / Privacy Policy

最后更新 / Last updated: 2026-08-27 · 适用扩展 / Applies to: Microsoft Edge 加载项「豆瓣北京图书馆馆藏查询助手」(Douban Beijing Library Finder)

本扩展旨在帮助豆瓣用户在浏览图书详情页时，快速查询北京图书馆（首都图书馆）的馆藏情况，发现可借阅的公共图书馆图书。 本页面说明扩展如何处理您的数据。核心原则是：本扩展不收集、不存储、不传输任何用户个人数据。

1. 我们收集什么？

我们不收集任何个人身份信息，包括但不限于：姓名、邮箱、账号、密码、Cookie、位置、浏览历史、设备信息等。

  • 扩展仅在您主动打开的豆瓣图书详情页中，读取该图书的 ISBN 与书名，用于查询该图书在北京图书馆的馆藏。
  • 我们不记录、不存储您访问过的网页列表，不发送统计或崩溃数据。

2. 数据如何处理与传输？

  • 馆藏查询请求由您的浏览器直接发送给北京图书馆系统接口（apps.jiatu.cloud / bjyth.jiatu.cloud），扩展本身不代理、不中转、不记录您的查询。
  • 查询过程中发送的仅有图书的 ISBN/书名信息。

3. 权限用途说明

  • activeTab：仅在您打开豆瓣图书详情页时读取页面 ISBN，用于查询。
  • declarativeNetRequest：修改图书馆接口请求头（Origin/Referer）以通过 CORS 校验，完成查询。
  • 主机权限（book.douban.com、apps.jiatu.cloud、bjyth.jiatu.cloud）：仅与图书馆查询和豆瓣图书页交互。

4. 第三方服务

  • 扩展不含广告、统计、崩溃收集或任何第三方 SDK。
  • 无 Cookie、无账号体系、无位置信息。

5. 数据留存 / 删除

由于我们不收集任何个人数据，因此没有需要留存、导出或删除的用户数据。卸载扩展即完全移除其影响。

6. 儿童隐私

本扩展不面向儿童亦不收集任何年龄相关的数据。

7. 政策变更与联系

若本政策变更，我们会更新本页面的「最后更新」日期。如有任何问题，请通过 GitHub Issues 联系我们，或发送邮件至 sxfanus@outlook.com。
